# The shape library

Seven shapes cover nearly every useful lead magnet. Each has a cost, a moment where it is the right choice, and a way it fails. The point of naming them is to stop a run producing fifteen versions of the same quiz.

The rule for a fifteen idea run: at least one idea from every shape. Not because all seven are worth building, but because writing one of each forces the run past the first three ideas, which are always the same three.

Cost is given as working time to build a first honest version, by one person, on a single page. Money cost is near identical across all seven: a page, a form endpoint and an email tool the business already pays for. Because money does not separate them, time is the cost that decides between shapes.

---

## 1. Calculator

**What it is.** A user enters a few numbers and receives a computed figure: money lost, money earned, hours saved, a date.

**Good for.** Making a problem visible with a number the user did not have. It is the strongest shape for proving a skill, because the arithmetic can be checked by hand.

**Cost to build.** One long day. The arithmetic is trivial; the empty state, the suppression rules and the gate take the time.

**When to use.** When the paid offer starts from a figure, and when the user already knows the inputs without looking anything up.

**Failure mode.** A calculator that answers a question nobody asks. The classic version is a savings calculator for a service the user has not yet decided they need. The fix is closeness, not design: compute the number the offer starts from, not an interesting number.

**Smallest honest version.** One field, one multiplication, one figure, one sentence explaining the arithmetic.

---

## 2. Assessment

**What it is.** The user answers a set of questions and receives a score, a band or a profile, usually with a named weakest area.

**Good for.** Ideas that are matters of judgement rather than arithmetic, and buyers who enjoy finding out where they sit. It also produces a natural opening line for a sales conversation.

**Cost to build.** Two to four days. The questions are quick; the scoring bands, the wording of each band and the honesty of the profile are not.

**When to use.** When there is no single number that captures the problem, and when the offer is an audit or a review.

**Failure mode.** A quiz with a score attached. Twelve questions, a number out of 100, and no consequence: the user learns their score, feels something, and has nothing to do next. The test is whether the result names one thing to change and why it is first.

**Smallest honest version.** Five questions, one score, one named weakest area, one sentence on what to do about it.

---

## 3. Swipe file

**What it is.** A set of ready-made words: messages, emails, scripts, policy wording, subject lines. The user copies and sends.

**Good for.** Audiences who already know what they want to say and want it written. It is the cheapest shape and the fastest to use.

**Cost to build.** An afternoon, plus whatever time the wording needs to be checked against rules that apply to the trade.

**When to use.** When the offer installs a process and the magnet can be the first artefact of that process. It also works as a second magnet for a list that already has a calculator.

**Failure mode.** A document that proves nothing. Nothing is computed, so the user cannot see a skill behind it, and the offer has to introduce itself from a standing start. It also dates: wording that matches a platform's current format stops matching it.

**Smallest honest version.** Five messages, each with a one-line note on when to send it.

---

## 4. Template pack

**What it is.** A structured file the user fills in: a spreadsheet, a document, a project board. The value is the structure, not the content.

**Good for.** Recurring work with a shape: a monthly close, a client onboarding, a content calendar.

**Cost to build.** One to three days. The structure is quick; making it survive a real month of use is the work.

**When to use.** When the offer depends on a repeatable routine, and when the user has already tried to build the routine and given up.

**Failure mode.** A beautiful template that needs discipline the user does not have. It is opened once, filled with three rows, and abandoned. The fix is to make the first row self-filling or to pair it with a short course.

**Smallest honest version.** One tab, six columns, two example rows, one instruction line at the top.

---

## 5. Checklist

**What it is.** A list of things to do or check, in order, with enough detail that the user can act without asking.

**Good for.** Reducing a fear of missing something. It is the most forwardable shape, because a list is easy to send to a colleague.

**Cost to build.** Two hours. The cheapest thing on this page by a wide margin.

**When to use.** When the risk is omission rather than effort, and when the audience is at the start of a process.

**Failure mode.** A list of obvious items that teaches nothing. "Write a business plan" is not a checklist item. The second failure is length: past about twenty items nobody finishes, so the useful item at 18 is never seen.

**Smallest honest version.** Twelve items, each one action, ordered by when it happens, with the one item people skip marked.

---

## 6. Short course

**What it is.** A sequence of emails or short lessons that teaches one thing over several days.

**Good for.** Building a relationship with an audience that is not ready to act today, and for topics where the value is in the sequence rather than in one artefact.

**Cost to build.** Three to five days of writing, plus a sending setup. The most expensive shape in writing time, and the slowest to deliver value.

**When to use.** When the offer needs a relationship before it can be sold, and when the buyer's problem takes more than one sitting to explain.

**Failure mode.** Five emails that each restate the same idea. The user learns the shape of the idea in email one and stops opening by email three. The second failure is silence: a course with no ask at the end teaches and sells nothing.

**Smallest honest version.** Three emails, one idea each, one action per email, one ask in the last.

---

## 7. Data lookup

**What it is.** The user picks a category, region or date and receives a reference value: a benchmark, a rate, a deadline, a wait time.

**Good for.** Questions with a factual answer the user cannot easily find, and for trades where a benchmark settles an argument.

**Cost to build.** Two days to a week, depending on where the data comes from, plus a maintenance budget forever.

**When to use.** When you own or can verify the data, and when the answer changes slowly enough to keep.

**Failure mode.** A table that goes stale quietly. The page keeps working, the numbers keep looking authoritative, and the user acts on a figure from two years ago. The second failure is provenance: a lookup with no source line is a rumour with a search box.

**Smallest honest version.** One category, one figure per row, a dated source line under the table, and a visible "last checked" date.

---

## Choosing between shapes

Two shapes usually survive a scoring run for the same niche. The choice between them is rarely about quality and almost always about which one produces the number or the artefact the paid offer starts from.

| If the offer starts from | Build this shape |
| --- | --- |
| A figure the buyer does not have | Calculator |
| A judgement about where to start | Assessment |
| A process the buyer must run | Swipe file or template pack |
| A risk of missing something | Checklist |
| A change of habit | Short course |
| A fact the buyer cannot find | Data lookup |

One more rule, from experience rather than arithmetic: the first magnet for a list should be a calculator or a checklist. They deliver in under two minutes, which is all the attention a first visit usually has.
